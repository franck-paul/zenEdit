## Description

Ce plugin permet de basculer temporairement vers un affichage simplifié pendant l'édition d'une entrée (billet, page, …).

Un bouton sur la barre d'outil de l'éditeur et utilisant le symbole yin et yang permet de basculer vers cet affichage. L'enregistrement de l'entrée en cours d'édition provoquera le retour vers l'affichage habituel.

Notez qu'il n'est utilisable qu'avec l'éditeur classique de Dotclear.

## Réglages

Ce plugin est réglable depuis les préférences utilisateur (onglet mes options > Mode zen pour l'éditeur dcLegacyEditor) avec :

- Une option pour basculer en mode plein écran (si le navigateur et le système le permettent)
- Le choix d'un fond d'écran à choisir parmi une liste (un exemple est fourni à la volée)
- Une option pour réduire les marges gauches et droites (utile sur un petit écran)
